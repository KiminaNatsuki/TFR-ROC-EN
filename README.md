# The Fire Rises: One Island, One Determination (English Translation)

This is an **English translation** submod for the Hearts of Iron IV modification **The Fire Rises: One Island, One Determination**, also known as **The Fire Rises: Republic of China** (TFR-ROC).

## Installation
1. Subscribe to the main [**The Fire Rises**](https://steamcommunity.com/sharedfiles/filedetails/?id=3350890356) mod.
2. Subscribe to the original [**The Fire Rises: One Island, One Determination**](https://steamcommunity.com/sharedfiles/filedetails/?id=3609728809) (TFR-ROC) submod.
3. Subscribe to this English Translation submod.
4. Make sure this translation submod is placed **below** the original TFR-ROC submod in your HOI4 launcher playset so the English localization files properly override the Chinese ones.
5. Switch your Paradox Launcher's language settings to English.
